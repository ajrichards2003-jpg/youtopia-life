# Youtopia Life

**Live Longer. Live Better. Live More.**

A future-focused discovery platform exploring longevity, biohacking, wellbeing, emerging science and better ways to live.

## Live site

Once GitHub Pages is enabled, the site will be available at:

**https://ajrichards2003-jpg.github.io/youtopia-life/**

### How to enable GitHub Pages (one-time)

1. Go to the repository: https://github.com/ajrichards2003-jpg/youtopia-life
2. Click **Settings** → **Pages** (left sidebar)
3. Under **Source**, select **Deploy from a branch**
4. Choose branch **main** and folder **/ (root)**
5. Click **Save**

GitHub will publish the site in 1–2 minutes.
